## 7. Debrief — дүгнэлт

Хамгийн үр дүнтэй нь Couch Potato аялал байв: хоосон талбар (BUG-05), оны муж (BUG-06), давхардал (BUG-07) гэсэн өгөгдлийн бүрэн бүтэн байдлын гурван томоохон согог энэ аяллаар олдов. Supermodel аялал нь хуудсыг нээсэн даруйд он форматын (BUG-01), тоолуурын (BUG-02), товчны өнгөний (BUG-04) согогийг илрүүлж, цааш нь хайлт (BUG-08), устгалын мессеж (BUG-09), урт текст (BUG-10), /old линк (BUG-11)-ийг олов. Saboteur аялал curl-аар буруу JSON-д 200 OK буцаах (BUG-12) болон «&»-ийг «&amp;» болгож хадгалах өгөгдлийн согог (BUG-13)-ийг гаргаж, BUG-02, BUG-05, BUG-06 нь зөвхөн UI биш серверийн түвшинд ч байгааг баталсан. Charter-аас гадуур санамсаргүй олдсон зүйл бол HTML-escape-ийн гажуудал (BUG-13), мөн байхгүй номыг DELETE хийхэд 200 OK буцаадаг тогтворгүй байдал юм. Мөн Enter товчоор хайлт/нэмэлт хийгддэггүй, нэмсний дараа талбар цэвэрлэгддэггүй, хайлтын үр дүнгээс устгахад шүүлтүүр алдагддаг зэрэг usability ажиглалтууд гарсан ч спецэд дүрэмгүй тул согог гэж бүртгээгүй. Шалгагдаагүй үлдсэн нь Safari/WebKit дээрх харагдац, дэлгэц уншигчийн хүртээмж, Unicode normalization-тэй хайлт тул эдгээр нь дараагийн session-ий charter болно. Лаб 1-ийн Playwright автомат тестээр тоолуур (BUG-02), хайлт (BUG-08), мессеж (BUG-09), /old (BUG-11), баталгаажуулалт (BUG-05, 06, 07) зэрэг тодорхой хүлээгдэх утгатай согогууд хялбар баригдана. Харин ногоон «Устгах» товч (BUG-04), мянгатын таслал (BUG-01), урт текстийн layout (BUG-10) зэрэг нь assertion урьдчилж бичээгүй бол автомат тест анзаарахгүй — хүний нүдээр л олддог. Иймээс автомат регресс тест ба exploratory session бие биеэ нөхдөг гэж дүгнэв.
