## Ажиллуулах заавар

1. Node.js суусан эсэхийг шалгана.
2. Terminal дээр төслийн хавтас руу орно.
3. Дараах командыг ажиллуулна:

   ```bash
   node app.js
   ```

4. Browser дээр http://localhost:3000 хаягийг нээнэ.

## Туршилтын зорилго

Уншлагын жагсаалт веб аппликейшнийг хар хайрцгийн exploratory testing аргаар шалгаж, SBTM session зохион байгуулан, илэрсэн алдаануудыг давтан шалгаж, нотолгоотой bug report бэлтгэнэ.

## Туршилтын үр дүн

Туршилтын charter, 60 минутын session-ийн тэмдэглэл болон баталгаажуулсан алдааны тайлангуудыг холбогдох файлуудад оруулна.

- `charter.md` — туршилтын зорилго, хүрээ, tour-ууд
- `session-report.md` — session-ийн хугацаа, үйл явц, тэмдэглэл
- `bugs/` — алдааны тайлангууд
- `evidence/` — API болон бусад текстэн нотолгоо
- `screenshots/` — дэлгэцийн зураг

## Debrief

Энэ хэсгийг exploratory testing session дууссаны дараа бодит үр дүнд үндэслэн бөглөнө. Хамгийн үр дүнтэй байсан tour-ууд, tour тус бүрээр илэрсэн алдааны тоо, charter-аас гадуур илэрсэн асуудлууд, дараагийн удаа шалгах хүрээ болон Playwright автомат тестээр илрүүлж болох, хүний нүдээр шалгах шаардлагатай алдаануудыг 8–10 өгүүлбэрээр дүгнэнэ.
