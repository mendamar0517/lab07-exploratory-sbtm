# BUG-04: Аюултай «Устгах» товч улаан биш, ногоон өнгөтэй

Орчин:  Уншлагын жагсаалт v2.0, Chromium 153.0.8010.12, Linux x86_64 (Node.js v22.23.4), 2026-10-24

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном), браузерт http://localhost:3000 нээсэн

## Дахин гаргах алхам

1. Хуудсыг нээнэ.
2. Хүснэгтийн мөр бүрийн баруун талын «Устгах» товчны өнгийг харна.

Хүлээгдэж байсан: Спец: «Аюултай үйлдлийн товч (Устгах) улаан өнгөтэй.»

Бодит үр дүн:     «Устгах» товч ногоон дэвсгэртэй (rgb(44,122,75)) — ногоон нь ихэвчлэн «зөв/батлах» үйлдлийг илэрхийлдэг.

Ноцтой байдал: Minor — функц ажиллана, гэхдээ хэрэглэгч аюултай үйлдлийг андуурч дарах эрсдэлтэй.
